# Командный бот

Телеграм-бот для рабочего чата. Он запоминает сообщения в Pinecone и отвечает по этой переписке. Сделан на Haystack 2.x и PyTelegramBotAPI. Эмбеддинги и ответы идут через OpenAI, адрес API — proxyapi.ru.

Бот подходит и для группы, и для личного чата.

## Что умеет

- Сохраняет каждое текстовое сообщение вместе с автором, чатом и временем.
- На «что думаешь?» отвечает по текущей теме: своё мнение и несколько вариантов. После `/start_listening` для такого вопроса берётся весь разговор сессии, а не только последние фразы.
- `/start_listening` начинает сессию обсуждения.
- `/stop_listening` присылает итог: тема, тезисы и как продолжить разговор. Если был спор, бот добавляет своё мнение. Если договорились о действиях, пишет, кто что делает.

Обычные сообщения бот не комментирует, только запоминает. Ответ приходит на упоминание, а в личном чате ещё и на короткое уточнение.

Память этого бота лежит в отдельном пространстве имён Pinecone и не смешивается с другими проектами в том же индексе.

## Установка

Нужен Python 3.12. В PowerShell из папки проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

После активации в начале строки появляется `(.venv)`.

Если активация не разрешена политикой Windows, один раз в этом же окне:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

## Ключи

Файл `.env` в репозиторий не входит. Рядом лежит образец `.env.example`.

Если `.env` ещё нет:

```powershell
Copy-Item .env.example .env
```

В `.env` заполняются токен BotFather, ключ OpenAI, адрес прокси, имена моделей, размерность эмбеддинга, ключ Pinecone, имя индекса и пространство имён. Размерность должна совпадать с уже созданным индексом.

## Запуск

Окружение должно быть активировано, файл `.env` заполнен. Одновременно может работать только один процесс бота.

```powershell
python bot.py
```

В терминале появится имя бота и строка `polling`. Остановка — `Ctrl+C`.

## Проверка в личном чате

1. Отправьте несколько фраз на одну тему. Ответа на них не будет.
2. Спросите `@имя_бота Что думаешь?` Бот ответит мнением и вариантами по этой теме.
3. Отправьте `/start_listening`, напишите ещё несколько реплик и завершите сессию командой `/stop_listening`. Придёт итог обсуждения.

В группе бот видит чужие реплики, только если в BotFather выключена Group Privacy: `/mybots` → бот → Bot Settings → Group Privacy → Turn off. После этого бота нужно удалить из группы и добавить снова.

## Состав

Пайплайны собраны в `PipelineManager` (`pipelines/manager.py`):

- Индексация считает вектор сообщения и больше ничего не делает. В Pinecone документ записывает менеджер.
- Поиск (`query_pipeline`) превращает вопрос в вектор и через `PineconeEmbeddingRetriever` возвращает близкие реплики.
- Резюме берёт эти реплики, собирает промпт в `ChatPromptBuilder` и отдаёт его в `OpenAIChatGenerator`. Ответ на упоминание идёт по этому же пути.

`bot.py` принимает сообщения Telegram. `check_model.py`, `check_indexing.py`, `check_query.py` и `check_summary.py` проверяют пайплайны без Telegram и удаляют пробные записи.
